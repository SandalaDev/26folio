# sandala.dev

Abe Sandala's portfolio and consulting platform. The application is a
static-first Next.js site that presents work, capabilities, professional
narrative, and selected content from the separate Scrumtrulescent Magazine
project.

## Local development

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run lint
npm run typecheck
npm run build
npm run test:os
```

Environment variables are documented in `env.example`. Do not commit
`.env.local`.

## Agent OS

This repository uses the harness-agnostic Agent OS in `AGENTS.md` and
`OPERATING_MANUAL.md`.

```bash
bash setup.sh
bash scripts/os.sh start
bash scripts/os.sh context
bash scripts/os.sh checkpoint "next step"
bash scripts/os.sh end
```

Open `dashboard.html` for current work, intent-traced progress, and recovery
information. Open `guide.html` for the complete operator guide. Both files are
generated by `os render` and must not be edited.

Current product context lives in:

- `project-spine/00-brief.md` and `00-interview.md`
- `project-spine/01-charter.md`, `02-decisions.md`, and `03-roadmap.md`
- `project-state/state.json`, `completion.md`, and `decisions.md`

The detailed legacy spine, 75 completed task records, prior epics, slice plans,
and content plans remain as historical evidence. See
`memory/legacy-agent-os-migration.md`.

## Git flow

The project uses `trunk-dev` flow:

1. Create one `feature/EPIC-XXX` branch from `dev`.
2. Open the epic PR into `dev`.
3. Promote reviewed integration work from `dev` to `main`.

The pre-push hook prevents accidental direct pushes to either trunk. Tests and
human review remain explicit project work; the OS does not turn them into push
gates.

## Updating Agent OS

Preview template changes before applying them:

```bash
bash scripts/update-from-template.sh \
  --from git@github.com:SandalaDev/agenticOS.git \
  --dry-run
```

The updater replaces OS machinery while preserving project-owned state,
backlog, handoffs, planning, and spine files. Review `.gitignore`, project
scripts, project-specific skills, and package changes after every update.
