# Roadmap

## P1 — Preserve and operationalize the current product

`ROAD-001` through `ROAD-003` cover the portfolio foundation, signature visual
system, and the narrative/capability work recorded in EPIC-001 through
EPIC-021. Those implementation milestones are delivered; their real-world goal
signals remain unvalidated until launch.

`ROAD-004` is active. It begins with EPIC-022, which replaces the broken legacy
Agent OS without rewriting portfolio code or losing project history. It then
collects the owner-review, contact, deployment, environment, accessibility, and
performance work needed for a credible launch.

## P2 — Validate outcomes after launch

`ROAD-005` is driven by evidence rather than speculative redesign: real inquiry
quality, technical opportunities, reader behavior, performance data, and owner
feedback determine what changes next.

## Sequencing rationale

The portfolio already contains substantial shipped design and content work.
Continuity and launch readiness now create more value than another broad visual
wave. The preserved legacy roadmap remains at `project-spine/09-roadmap.md` for
historical detail; this file represents the current delivery sequence.
